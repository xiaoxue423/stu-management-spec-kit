# Quickstart: 新增与编辑学生成绩录入

## 1. 启动后端

```bash
python3 -m pip install -r backend/requirements.txt
python3 -m uvicorn backend.main:app --reload --host 127.0.0.1 --port 8000
```

## 2. 启动前端

```bash
cd frontend
npm install
npm run dev
```

## 3. 手工验证用例

1. 打开 `http://localhost:5173`，页面显示“学生列表”和“新建”按钮。
2. 点击“新建”，填写姓名/分数，性别下拉仅展示“男”“女”，且不出现学号输入项。
3. 选择月份（1-12）与科目（数学/语文/英语），保存后列表出现新增学生，学号由后端自动生成（0001 起）。
4. 在该学生行点击“编辑”，弹窗回显已有信息，修改任意字段后保存成功。
5. 编辑状态下不修改直接保存，应提示“未检测到变更”并阻止提交。
6. 输入非法分数（如 `101`、`88.888`）应被拦截并展示错误。
7. 断开后端后刷新列表，应显示失败提示与“重试”按钮。
8. 连续新建两条数据，确认学号按 0001、0002 递增。
9. 将后端学号序列模拟到上限后再新建，应收到“号段已满”类提示并阻止创建。

## 4. 性能核验记录（手工）

- 弹窗打开：连续 20 次操作，主观可交互时间稳定在 1 秒内。
- 提交流程：连续 20 次新建/编辑，接口响应均在 2 秒内（本地开发环境）。
